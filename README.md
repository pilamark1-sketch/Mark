# Mark

This is a professional resume webpage template.

## Usage

1. Open `index.html` in your web browser to view the resume.
2. Edit the content in `index.html` to personalize with your information.
3. Modify `css/styles.css` to customize the appearance.

## Features

- Responsive design that works on desktop and mobile
- Clean, professional layout
- Sections for summary, experience, education, skills, and projects
- Easy to customize

## Customization

Replace the placeholder text in `index.html` with your actual information:
- Update the header with your name and contact details
- Fill in your professional summary
- Add your work experience, education, skills, and projects
- Adjust colors and fonts in `css/styles.css` as needed
